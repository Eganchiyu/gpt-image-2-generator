# Mask 绘制指南

> 改图模式下的遮罩绘制说明。

---

## 什么是 Mask？

Mask 是一张和参考图**同尺寸的透明 PNG**，用于告诉 API 哪些区域需要修改。

```
原图 + Mask → API 只处理白色区域 → 输出修改结果
```

---

## Mask 规则

| 颜色 | 含义 |
|------|------|
| ⬜ **白色 (RGB 255,255,255)** | ✅ 这个区域会被 API 修改 |
| ⬛ **透明 / 黑色** | 🚫 这个区域完全保留原图，不动 |

---

## 使用内建画布绘制

### 笔刷

1. 切换到 **🎨 改图模式**
2. 上传 1 张参考图 → 自动弹出画布
3. 在图上**拖动鼠标涂抹白色** — 白色笔迹 = mask 区域
4. 滑块调节笔刷大小（3px ~ 80px）

### 橡皮

1. 点击 **🧹 橡皮** 按钮
2. 在画布上拖动 — 擦除白色笔迹（恢复透明）

> 再次点击 **🧹 橡皮** 切换回绘制模式。

### 清除

点击 **🗑 清除** — 一键清空全部白色笔迹。

## 实际示例

### 示例 1：换背景

```
参考图：人像照片
Mask  ：在人物轮廓外用白色涂抹，人物本身留透明
Prompt ："把背景换成樱花树下，保持人物不变"
→ API 只改背景，人物不变
```

### 示例 2：改局部细节

```
参考图：室内照片
Mask  ：在要改的椅子上涂白色，其他都透明
Prompt ："把椅子换成木质椅"
→ API 只改椅子
```

### 示例 3：添加物体

```
参考图：桌面照片
Mask  ：在想要放杯子的区域涂白色
Prompt ："在桌上放一杯咖啡"
→ API 只在白色区域添加杯子
```

---

## 注意事项

- 白色边缘尽量**柔和处理**，不要有生硬的锯齿（可以适当降低笔刷硬度）
- 如果 mask 涂到了不该改的地方，用橡皮擦掉
- 大范围编辑（> 50% 图面）建议直接用生图模式
- Mask 通过 Canvas 以**原始分辨率**导出，不会因为屏幕缩放而失真
