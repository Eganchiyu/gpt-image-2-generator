# 故障排查

---

## 问题：生成失败，返回 401/403

**症状**：`生成图像时出错: 401 Unauthorized`

**原因**：API 密钥无效或过期。

**解决**：
1. 检查 `.env` 中的 `OPENAI_API_KEY` 是否正确
2. 确认 `OPENAI_BASE_URL` 是否和你的代理服务匹配
3. 重新生成 API Key 并更新 `.env`

---

## 问题：生成失败，返回 429

**症状**：`生成图像时出错: 429 Too Many Requests`

**原因**：API 配额用完或限流。

**解决**：
1. 等待几分钟后重试（程序会自动重试最多 10 次）
2. 检查 API 账户的用量/配额
3. 升级账户或更换更高配额的 Key

---

## 问题：Mask 画布不显示

**症状**：切换到改图模式、上传参考图后，画布区域没出现。

**原因**：
- 当前不在改图模式
- 图片格式不支持导致加载失败
- 浏览器 Canvas 被禁用

**解决**：
1. 确认切换到 **🎨 改图模式**（顶部按钮应为紫色激活态）
2. 打开浏览器控制台 (F12) 查看是否有加载错误
3. 换 PNG/JPG 格式重试

---

## 问题：Mask 画布坐标不准

**症状**：画的笔刷位置和鼠标偏移。

**原因**：Canvas CSS 缩放和实际分辨率不一致。

**解决**：
- 这是已知行为。画布以图片**原始分辨率**渲染，CSS 只做屏幕适配
- 如果你发现明显偏移，检查 `draw-canvas-wrapper` 是否有自定义 CSS 冲突

---

## 问题：生成结果图片不显示

**症状**：成功返回但图片区域为空白。

**原因**：
- 浏览器不支持 data URL 显示
- `revised_prompt` 字段缺失（正常行为）

**解决**：
1. 检查控制台 Network 标签，确认 `/generate` 返回了 `image_url`
2. 换 Chrome/Edge 浏览器

---

## 问题：端口 5000 被占用

**症状**：`OSError: [Errno 98] Address already in use`

**解决**：
```bash
# 找到占用端口的进程（git-bash）
netstat -ano | grep 5000

# 结束对应 PID 的进程
kill <PID>

# 或者改端口
set PORT=5001 && python run.py
```

---

## 问题：上传大图卡顿

**症状**：上传几 MB 的图片时页面无响应。

**原因**：`MAX_CONTENT_LENGTH` 已限制 50MB，超过会直接报错。

**解决**：
1. 压缩图片到 5MB 以下
2. 检查 `app.config['MAX_CONTENT_LENGTH']` 是否需要调整

---

## 问题：改图模式修改不了图片

**症状**：mask 画了但生成结果没有变化。

**原因**：
- mask 的白色区域太少或没有
- `hasDrawnMask` 标志未触发（没有真正绘制内容）

**解决**：
1. 确保画布上有**白色笔迹**（确认模式指示器显示 ✏️ 绘制模式）
2. 检查 retry 面板是否有错误信息
3. 尝试用更大的笔刷多画一些区域

---

## 问题：.env 配置不生效

**症状**：运行报 `OPENAI_API_KEY not set`。

**解决**：
```python
# 确认 app.py 顶部有
from dotenv import load_dotenv
load_dotenv()
```

确认 `.env` 文件在**项目根目录**（和 `app.py` 同级），而不是在其他子目录。
